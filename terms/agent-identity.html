Agent identity

first seen 2026-W34 · needed by 1 · 11 links · 1 min read

A verifiable, durable identity for a persistent agent: a stable named character rather than a disposable thread, and the first layer on which permissions, reputation and accountability can be built. Product-side in Grok Bot, governance-side in Berman's essays, protocol-side in NLIP.

Also seen as persistent bot identity, agent identity layer

How the sources use it

  • Gergely Orosz (Gergely Orosz, 2026-09-22) Entra ID identities that make an agent a user in Task Manager with human-equivalent observability, and Defender scanning for agents that do not self-register. Recurring and cross-source (Berman, arXiv, Frontier Labs).
  • Forward Future team (Matthew Berman, 2026-09-21) Google giving the household agent its own account and permissions.
  • Anthropic (Frontier Labs, 2026-09-17) a per-agent identity that persists through model upgrades, for auditability. Cross-source (Matthew Berman, arXiv cs.AI); new to this source.
  • Zhenyu Zhao, Roy Zhao (arXiv cs.AI, 2026-09-12) cross-source (Berman); PAI-Bench is the evaluation counterpart to Berman's identity-contract argument.
  • Luyi Xing (arXiv cs.AI, 2026-09-03) Berman's term from the Instance Birth Certificate essay; NLIP's security-by-design section is the protocol-level neighbour.
  • Forward Future (Matthew Berman, 2026-08-30) verifiable, durable identity for persistent agents as the first governance layer.
  • Matthew Berman (Matthew Berman, 2026-08-20) Grok Bot's design of giving each agent a stable, named "character" rather than disposable threads, which Berman says drives daily habitual use.
