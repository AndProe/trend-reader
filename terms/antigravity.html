Antigravity

Agent platforms have so far been built for software engineering, where the environment is a repository and the feedback is a test result. Antigravity is the same pattern applied to research: the agent orchestrates queries across biological databases, retrieves predicted protein structures, inspects genomic neighbourhoods and synthesises literature, while the researcher decides which questions to ask and which evidence counts.

The commercially interesting part is the division of labour rather than the capability. The agent performs the narrowing — millions of unannotated sequences filtered to a handful of candidates — and the human adjudicates at each step, with the platform supplying shared mutable state through an embedded structure viewer that both parties can annotate. The stated gain is compressing days of fragmented database work into one session, not discovery; the leads it produces still require wet-lab validation, which remains the binding constraint.

Also seen as Google Antigravity

Deeper dive

How it works. The platform exposes an agent loop over domain tools: database query and filtering, sequence-homology checks against curated references, structural retrieval and superposition, genomic-context inspection, literature synthesis and finally generation of a bench protocol. The 3D viewer is bidirectional — the agent can drive it to highlight regions, and a researcher's annotations synchronise back into the agent's context — which is a different interaction model from prompt-and-review and gives the pair a shared workspace rather than a transcript.

Why it matters now. Domain workbenches are how a general Agent harness becomes defensible: the harness, not the model, supplies the actions, and independent work this period has measured large effects from harness design on both accuracy and token cost. Scientific workflows are a strong fit because the verification steps are explicit and stackable — sequence novelty, structural homology, genomic plausibility — which lets Verification loops substitute for the agent's own confidence before anything expensive happens.

Trade-offs. The leads produced are computational predictions; the published example is explicit that wet-lab validation has not been done, and narrowing a search space well is not the same as being right. A platform-specific workbench also ties a research workflow to one vendor's agent and one vendor's structure predictions, which is a durable dependency for a lab. And the compression claim is about triage time rather than about discovery rate, so the return depends on how much of a given field's cost sits in triage.

What to watch. Whether any platform-generated lead clears wet-lab validation, whether domain workbenches appear beyond biology, and whether the shared-canvas interaction model spreads to other agent products or remains specific to structural work.
