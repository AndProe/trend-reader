Codex-ChatGPT merger

first seen 2026-W35 · 8 links · 3 min read

OpenAI has been folding Codex, its coding agent, into ChatGPT, so that the same underlying agent machinery serves a software engineer fixing a bug and an analyst preparing a report. The visible form is ChatGPT Work, in which the full Codex harness runs on a managed cloud computer inside the ChatGPT interface. The local command-line agent is being merged into a hosted stack that OpenAI operates.

OpenAI's stated rationale is strategic rather than operational. Rather than maintaining separate products for different audiences, it is betting that one interface can adapt to whoever is using it, and that the agent harness proven on code is general enough to carry every other kind of work. For an executive that has two implications. It means OpenAI's coding tool and its enterprise assistant are becoming the same purchase, which simplifies procurement but concentrates dependence. And it means the cloud computer model, where the agent works on infrastructure the vendor controls, is becoming the default, with consequences for data governance.

Deeper dive

What happened. Codex began as a separate coding agent with a command-line interface and a cloud mode. Over 2026 OpenAI has been merging it into ChatGPT: one interface, one harness, one account. The clearest product expression is ChatGPT Work, released in July, which runs the full Codex harness on a Managed agent computer inside ChatGPT for users who do not write code. The technical move is from a local agent, which runs on the user's machine with access to local files, to a managed cloud stack, which runs in Remote sandboxes the vendor provisions.

Why it matters now. The rationale offered by the Codex team is that this is a bet on a single personal-AGI interface, one that adapts to a technical user and a non-technical user without either needing a different product. The Coding harness is the enabling technology: the loop that plans, calls tools, checks results and continues is the same whether the tools are compilers or spreadsheets. If the bet holds, the distinction between a coding agent and a general assistant disappears, and the vendor that owns the harness owns the workflow. That is consistent with the broader Vertical integration of AI labs, in which labs own model, harness, runtime and hosting rather than the model alone. Internal evidence supports the bet: nearly all work at OpenAI is said to run through the Codex harness, including non-engineering departments.

Trade-offs. A single interface reduces product complexity and lets improvements in the harness reach every user at once, but it forces compromises: an engineer's needs for local files, custom tooling and offline work differ from an analyst's, and a managed cloud computer cannot serve both without friction. Hosting everything on OpenAI infrastructure raises data-residency and retention questions that a local agent did not. And the strategy assumes the harness generalises, which is plausible for document work and less proven for tasks tied to specialised enterprise systems.

What to watch. Whether the local Codex CLI survives as a first-class product or becomes a thin client, how Personal agent workflows built in ChatGPT Work differ from engineering patterns, and whether competitors converge on the same single-interface design or keep coding and general assistants separate.

technique

Coding harness

A coding harness is the software layer wrapped around a language model that turns it into a working coding agent: the loop that manages context, calls tools, runs tests and decides what to do next.

Personal agent workflows

Personal agent workflows are the ways individuals use a single AI agent, often described as a chief of staff, to triage email, summarise meetings, manage the calendar and delegate to specialised sub-agents over chat.

15 linkstechnique

Managed agent computer

A managed agent computer is a vendor-operated persistent virtual machine assigned to each user or agent, on which the agent works and which the user can watch, as opposed to an agent that runs on the user's own device.

9 linkstechnique

Remote sandboxes

Remote sandboxes are isolated cloud machines, often micro-VMs, spun up per agent session so that coding and computer-use agents run on dedicated infrastructure rather than on a developer's laptop.

6 linksconcept

Vertical integration of AI labs

Vertical integration of AI labs is model developers extending from models into the layers around them: buying developer toolchains, owning coding harnesses, moving into consumer verticals and cutting off third-party platforms.

8 linksproduct

Codex

Codex is OpenAI's coding agent, available as a command-line tool and a cloud service, that gives a GPT model file, shell and tool access so it can carry out engineering tasks end to end.
