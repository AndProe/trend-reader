Codex-ChatGPT merger

first seen 2026-W35 · 8 links · 1 min read

OpenAI's consolidation of its Codex coding agent and ChatGPT into one interface and harness, which Tibo Sottiaux told Berman is a bet on a single personal-AGI interface that adapts to technical and non-technical users alike rather than a product consolidation. In his later interview with Orosz the merger takes the form of ChatGPT Work, the full Codex harness running on a managed cloud computer inside ChatGPT.

How the sources use it

  • Gergely Orosz (Gergely Orosz, 2026-09-09) merging a local agent into a managed cloud stack. Cross-source mention (Berman).
  • Matthew Berman (Matthew Berman, 2026-08-24) the ongoing consolidation of OpenAI's coding and general chat products into one interface and harness. Established, now explained from OpenAI's own rationale.

Related terms

technique

Coding harness

The tooling layer around a model that turns it into a coding agent (Claude Code, Codex, Cursor, Devin, Ramp's Inspect on OpenCode), now the product unit of the agentic era and extended beyond code.

needed by 9 · 28 linksconcept

Personal agent workflows

Individuals using a single agent or chief-of-staff bot to triage email, summarise meetings, coordinate the day and delegate to sub-bots over chat; the consumer-side pattern Grok Bot and Orosz's inbox agent illustrate, and Sottiaux's rationale for a universal personal agent.

15 linkstechnique

Managed agent computer

A vendor-operated persistent virtual machine per user or agent (Grok Bot's default), contrasted with the local-first default of Codex and Cursor; convenient, and the reason bots share logins.

9 linkstechnique

Remote sandboxes

Cloud machines spun up per agent session for unlimited concurrency and central configuration; how Ramp runs Inspect and the infrastructure behind hosted agent computers.

6 linksconcept

Vertical integration of AI labs

Frontier labs extending from models into the layers around them, buying developer toolchains (Anthropic and Bun, OpenAI and Astral), owning coding harnesses and cutting off third-party platforms, so that the product, not the model, is where they compete; the counter-position to model-agnostic architecture.

8 linksproduct

Codex

OpenAI's coding agent, used by Asana for migrations, cited as the enterprise token-share example, and the CLI agent in ToolGate; being merged into ChatGPT per Sottiaux.
