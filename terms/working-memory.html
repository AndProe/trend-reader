Working memory

first seen 2026-W30 · 6 links · 1 min read

An agent's ability to hold and update state across steps, one of two failure modes (with belief revision) named in the partially observable MNIST-PRO benchmark.

Also seen as agent working memory, state tracking

How the sources use it

  • Mingyang Mao, Wyatt Mackey, Xiaomin Lin (arXiv cs.AI, 2026-09-16) cross-source (Technically); edits to working memory are one of the three sources of staleness named.
  • Vernon Toh (arXiv cs.AI, 2026-08-31) and Belief revision — the two failure modes named.
  • Paul Iusztin (Technically, 2026-07-21) file-based memory first, vector or graph stores later.
