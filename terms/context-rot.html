Context rot

first seen 2026-W30 · 9 links · 1 min read

The degradation of an agent's performance and memory reliability as its conversation history accumulates; Tunguz's reason to ask how long an agent should live.

Also seen as context degradation, long-session decay

How the sources use it

  • Yukai Wu, Yuanjing Yang, Le Zhou, Shaokun Han, Haoyu Wang, Zirui Tang, Weihuang Zheng, Maxm Pan, Xuanhe Zhou, Fan Wu (arXiv cs.AI, 2026-09-24) Cross-source (Simon Willison); conflicting versions and stale evidence as a property of the environment rather than of the session.
  • Trang Nguyen, Eulrang Cho, Bingqing Chen, Tim Dettmers (arXiv cs.AI, 2026-09-22) Cross-source (Gergely Orosz, Technically, Tomasz Tunguz); the authors name accumulated context drift as the failure their never-compact-a-compaction rule avoids.
  • Run-Ze Fan, Zihao Zhang, Simin Ma et al. (arXiv cs.AI, 2026-09-17) cross-source (Tomasz Tunguz, Technically); the failure the authors name is context overflow, which their context management mostly prevents.
  • Gergely Orosz (Gergely Orosz, 2026-09-17) Horthy's smart zone and dumb zone; work portioned so a session stays under about 150,000 tokens. New for this source; cross-source (Technically, Tomasz Tunguz).
  • Tomasz Tunguz (Tomasz Tunguz, 2026-08-24) degradation of agent performance and memory reliability as conversation history accumulates.
  • Paul Iusztin (Technically, 2026-07-21) named as the reason the harness must keep the context window clean.

Related terms

concept

Long context

Context windows of hundreds of thousands to a million tokens and what they enable and cost: multi-turn agent sessions, memory-bound serving, degraded reliability at the far end.

needed by 4 · 12 linksconcept

Working memory

An agent's ability to hold and update state across steps, one of two failure modes (with belief revision) named in the partially observable MNIST-PRO benchmark.

7 linksconcept

Persistent agents

Agents intended to run continuously, keeping memory, reputation and relationships across tasks, rather than on a scheduled or rationed basis; the aspiration behind always-on assistants and the case for local inference.

needed by 2 · 16 linksconcept

Memory poisoning

A malicious email, document or calendar invite hijacking a long-lived agent through its persistent context; the risk Tunguz sets against long agent lifetimes.

6 linkstechnique

KV cache

The transformer's per-token memory that grows with context; capacity limits long-context serving on SRAM machines, reuse across turns is the systems problem agentic serving turns on, and test-time training is proposed as a fixed-size alternative.

needed by 2 · 12 linkstechnique

Continual learning

Models that keep learning from deployment rather than staying frozen after training, updating on new tasks and users while retaining what they already know.
