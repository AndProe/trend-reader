MCP

first seen 2026-W23 · 8 links · 1 min read

Model Context Protocol, the standard for exposing tools to agents; hosted internally at Optiver so agents use company tools, and one of the protocols NLIP positions itself against.

Also seen as Model Context Protocol, MCP servers

How the sources use it

  • Gergely Orosz (Gergely Orosz, 2026-09-22) a centralised OS registry of local MCP servers, with built-in connectors for File Explorer and System Settings. Recurring and cross-source.
  • Forward Future team (Matthew Berman, 2026-09-17) Google Home exposing device control to agents through an MCP server. New to this source; Cross-source (Gergely Orosz, arXiv cs.AI).
  • Laxmipriya Ganesh Iyer (arXiv cs.AI, 2026-09-16) cross-source (Gergely Orosz, Technically, Frontier Labs); the paper's second study shows namespace merges across MCP servers as a hallucination surface a single registry cannot express.
  • Nilesh Verma, Nick Lim, Albert Bifet et al. (arXiv cs.AI, 2026-09-16) cross-source (Gergely Orosz, Technically); one of the interfaces driven from the specification layer.
  • David Krevitt (Technically, 2026-09-08) an auth vendor shipping an MCP server so agents wire auth correctly.
  • Luyi Xing (arXiv cs.AI, 2026-09-03) Orosz's term (Optiver hosting MCP).
  • Anthropic (Frontier Labs, 2026-08-27) one of the three control routes; the lab uses it as the default way an agent reaches a driver.
  • Gergely Orosz (Gergely Orosz, 2026-08-11) Model Context Protocol hosting so agents can use internal tools.
  • Tereza Tizkova (Technically, 2026-08-06) the reason the share of work that needs a screen keeps shrinking.
  • Matt Henderson (Technically, 2026-06-04) Ahrefs data pulled through MCP inside a Claude Code skill; a Sentry MCP recipe in the cookbook.

9 linksproduct

OpenClaw

An open-source, self-hosted agent harness that lives on a machine the user provides (a laptop, Mac Mini or VPS), connects any model to messaging apps such as Telegram and WhatsApp, keeps memory in Markdown files and a skills system, and reaches tools through MCP; the project that made "an agent living on your machine" a mainstream idea and the user-owned counterpart to managed agent computers like Grok Bot.

7 linksconcept

Specialised harnesses

Agent harnesses that bake in one domain's tools, prompts and guardrails and are sold as products, such as Harvey for legal research, Abridge for clinical notes, Sierra for customer service and Glean for enterprise search.

Agent protocols

The emerging interoperability layer for agents (MCP, A2A, NLIP): how agents call tools and talk to each other across vendors, with security designed in or not.
