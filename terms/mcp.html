MCP

first seen 2026-W23 · 8 links · 3 min read

MCP is a plumbing standard. A tool provider, whether an internal database, an authentication service, a home-automation hub or an operating system, runs an MCP server that describes what it can do. An agent connects to that server and can then call those capabilities without custom integration code. A trading firm hosts MCP servers so its agents can use internal tools; an auth vendor ships one so agents wire up login correctly; an operating system is adding a registry of local MCP servers.

For an executive MCP is the question of how agents touch the business. Every capability exposed through a server is something an agent can act on, which makes the server list both a security perimeter and an inventory of what has been automated. It reduces integration cost and is a hedge against lock-in, because any compliant agent can use the same servers. Deciding which systems get an MCP server, and who may connect, is now a governance task.

Also seen as Model Context Protocol, MCP servers

Deeper dive

How it works. An MCP server publishes a schema of tools, resources and prompts; an agent's client fetches that schema, presents the tools to the model, and relays the model's calls to the server. The protocol standardises discovery, argument formats and results, so a model trained to use tools in general can use any MCP-exposed tool in particular. Deployment patterns include internal hosting inside a company, vendor-shipped servers for products such as error tracking or authentication, device control such as a home platform exposing appliances, and operating-system registries that list local servers and provide built-in connectors. Leading model labs use it as the default route by which an agent reaches a hardware driver.

Why it matters now. MCP is one of the Agent protocols competing to define Agent interoperability, and it is the one with the widest deployment. Its spread is why the share of agent work that requires a screen keeps shrinking: when a tool has a server, the agent does not need to drive a user interface. A Coding harness typically ships with MCP support, and a Skill library often wraps MCP calls in reusable procedures. Competing designs, such as natural-language interaction protocols, position themselves against it on the grounds that a fixed schema is too rigid.

Trade-offs. The main costs are security and correctness. Every server is an attack surface: a compromised or malicious server can feed the agent misleading results or instructions, and centralised registries make the blast radius larger. Research on tool hallucination shows a second problem: when several servers are merged into one namespace the agent can invent tools that do not exist, and a single registry cannot express which combinations are valid. Governance therefore needs allow-lists, authentication per server and logging of every call. The convenience also creates a soft form of lock-in to whichever ecosystem holds the most servers.

What to watch. Operating-system level registries becoming standard, authentication and permission models built into the protocol, and whether a rival protocol wins the agent-to-agent layer while MCP keeps the agent-to-tool layer.

Related terms

concept

Agent interoperability

Agent interoperability is the ability of agents built by different vendors to work together across a shared platform or protocol, exchanging tasks, results and context without custom integration.

5 linkstechnique

Coding harness

A coding harness is the software layer wrapped around a language model that turns it into a working coding agent: the loop that manages context, calls tools, runs tests and decides what to do next.

needed by 9 · 28 linkstechnique

Skill library

A skill library is a store of reusable, named procedures that an agent can load and apply, whether taught by demonstration, written by hand as instructions, derived from failure diagnoses or compiled into executable artefacts.

9 linksproduct

OpenClaw

OpenClaw is an open-source, self-hosted agent harness that runs on hardware the user owns, connects any model to messaging apps such as Telegram and WhatsApp, and keeps memory in plain Markdown files alongside a skills system and MCP tool access.

7 linksconcept

Specialised harnesses

Specialised harnesses are agent products that wrap a general model in one domain's tools, prompts, data connections and guardrails, such as Harvey for legal research, Abridge for clinical notes, Sierra for customer service and Glean for enterprise search.

7 linkstechnique

Agent protocols

Agent protocols are the emerging standards that define how agents call tools, talk to each other and operate devices across vendors, with MCP, A2A, NLIP and a model hardware standard as the current proposals.
