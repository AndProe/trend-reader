Managed agent computer

first seen 2026-W33 · 9 links · 1 min read

A vendor-operated persistent virtual machine per user or agent (Grok Bot's default), contrasted with the local-first default of Codex and Cursor; convenient, and the reason bots share logins.

Also seen as hosted agent computer, virtual computer, cloud-first agent OS

How the sources use it

  • Dan McAteer (Latent Space, 2026-09-05) a vendor-operated persistent machine per user.
  • Matthew Berman (Matthew Berman, 2026-08-12) Berman's framing for Grok Bot spinning up a full, independently viewable cloud computer per agent by default, contrasted with Codex/Cursor's local-first default.
  • Tereza Tizkova (Technically, 2026-08-06) the "computer" layer, sold with the harness by Factory, Manus, Devin and Zo.
