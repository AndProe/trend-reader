AI agents

first seen 2026-W29 · needed by 20 · 33 links · 3 min read

An agent is a model wrapped in a loop: it reads a goal, decides on an action, runs a tool, looks at the result and repeats until the task is done or it gives up. The wrapping ranges from a coding assistant in a terminal to hosted agents that run workflows for people who never write code, to agents that act on home devices, place phone calls or handle a week of travel over text messages.

In 2026 the commercial shape became clear. Leading laboratories run thousands of agents concurrently inside their own engineering organisations, vendors sell inbound sales and support agents, and at least one "AI associate" has been sold on a $250,000 contract. Consumer adoption lags capability. For an executive the decisions are where agents can act rather than only answer, what each action costs in tokens, since agents consume far more input than chat, and who owns the failure when an agent errs. Agent spending is an operating cost, not a licence fee.

Also seen as agentic workloads, managed AI agents, agents

Deeper dive

How it works. The unit of work is a request loop: the model reasons, emits a tool call, the harness executes it in a sandbox or against an API, and the observation goes back into context. Long tasks add planning, memory across sessions, Sub-agents for parallel branches and verification steps that check outputs before the loop moves on. The model supplies judgement; the Coding harness or platform supplies tools, permissions, retries and the record of what happened. Capability at the frontier is therefore a joint property of Frontier models and the scaffolding around them, which is why laboratories now train models with their own agentic loops built in and why harness design has become a product category with its own margins.

Why it matters now. Agents shifted from answering questions to doing work in 2026: agents that decide what to do rather than wait in a chat window, agents that supervise and adjust laboratory experiments in real time, video-platform agents that recommend and generate at consumer scale, and hosted agents aimed at non-developers. Inside the frontier laboratories, thousands of concurrent agents are the cultural precondition for the software-factory style of engineering. The workload profile is different from chat: heavy input volume, many tool calls per task and long sessions, which drives cost, infrastructure and pricing decisions.

Trade-offs. Autonomy trades against control. The same loop that finishes a task without supervision can take an irreversible action, and serious deployments confine agents to selection, configuration and interpretation while a human keeps decisions that are hard to reverse. Reliability, not raw capability, is the gating factor for enterprise use; see Agent reliability and Long-horizon goals. The consumer gap persists because the value of an agent depends on its access to accounts, devices and money, which people are slow to grant.

What to watch. Phone calling and Browser control as the next action surfaces after text, Persistent agents with identity and memory that outlive a session, and enterprise token budgets as the metric that shows whether agent deployments are actually running.

Frontier models

Frontier models are the strongest AI models available at any moment, the tier that sets the state of the art and that everything else is measured against.

Coding harness

A coding harness is the software layer wrapped around a language model that turns it into a working coding agent: the loop that manages context, calls tools, runs tests and decides what to do next.

needed by 9 · 28 linkstechnique

Sub-agents

Sub-agents are parallel agents spawned inside a single run under a coordinator, each given a slice of the task and its own context, with results returned to the parent.

needed by 1 · 13 linksconcept

Persistent agents

Persistent agents are AI agents designed to run continuously and carry memory, identity and relationships across sessions, devices and tasks, instead of starting fresh on each request.

needed by 2 · 16 linksconcept

Long-horizon goals

Long-horizon goals are objectives that an agent pursues autonomously over days, maintaining coherence across billions of tokens and many sub-tasks rather than completing one request and stopping.

needed by 1 · 12 linkstechnique

Browser control

Browser control is the capability of an AI agent to operate websites and desktop applications through a persistent browser or computer session, clicking, typing and reading screens rather than calling an API.
