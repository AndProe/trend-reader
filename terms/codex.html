Codex

first seen 2026-W20 · needed by 2 · 15 links · 3 min read

Codex is OpenAI's answer to the coding-agent category: a program that takes a task description, works through a codebase on its own, runs tests and returns a change ready for review. It runs either locally as a command-line tool or in OpenAI's cloud, and it is the direct rival to Anthropic's Claude Code. Each lab's models favour its own agent, so choosing Codex is in practice choosing GPT.

Three facts make it more than a developer tool. Enterprises route a large share of AI spend through it: about 64 percent of enterprise output tokens in one analysis, the clearest example of coding agents dominating the token bill. Inside OpenAI it is the harness through which nearly all work runs, including finance, legal and recruiting, and it is being merged into ChatGPT so the same machinery serves non-engineers. And it has done real, large jobs: Asana's migrations, operating quantum laboratory hardware, and, controversially, holding the drafts of mathematicians whose proof work raised questions about who owns data placed in an agent's workspace.

Also seen as OpenAI Codex, Codex CLI

Deeper dive

How it works. Codex is a Coding harness around OpenAI's models. The command-line version runs on the developer's machine with access to local files and tools; the cloud version runs the same loop in a hosted sandbox. In either mode the agent reads the repository, plans, edits, executes commands, checks results and iterates until the task is complete or it needs input. Research papers use the Codex CLI as a standard agent for benchmark construction and for studying compaction and harness design, which is why it appears in the technical literature as well as in product coverage.

Why it matters now. Codex is at the centre of three developments. First, enterprise adoption: it is the reference example for Enterprise agent tokens, with output-token share reported at 64 percent of enterprise usage, and for AI-assisted migrations, where Asana used it to move code at scale. Second, OpenAI's own operations: the company is described as an agentic software factory in which nearly all engineering and much operational work flows through the Codex harness, and the product for non-engineers, ChatGPT Work, runs the same harness on a cloud computer. Third, the Codex-ChatGPT merger, which folds the coding agent into the consumer product on the theory that one harness can serve every kind of user. Codex also became entangled in the Navier-Stokes proof story, where the mathematicians stored their drafts in it and the question of data access followed.

Trade-offs. Like Claude Code, Codex is a single-model harness, so it is a commitment to one lab and not a neutral tool; enterprises that want to route across models put a proxy under it or use an open harness. Its use for non-coding work is promising but rests mainly on OpenAI's internal experience. And storing sensitive intellectual work inside a vendor-hosted agent raises retention and ownership questions that the mathematics episode brought into the open.

What to watch. Codex's standing against Claude Code on SWE-bench Verified and agentic benchmarks as models update, whether the merged product keeps a strong local mode, and whether the enterprise token share holds as Anthropic and Google compete on price.

Related terms

product

Claude Code

Claude Code is Anthropic's terminal-based coding agent: a harness that wraps a Claude model with file, shell and tool access so it can plan, edit, run and verify changes across a codebase on its own.

9 linksconcept

AI-assisted migrations

The use of coding agents to execute large framework, language, database or test-suite migrations that were previously too expensive to attempt, with retry-and-verify pipelines doing most of the mechanical work.

11 linksconcept

Personal agent workflows

Personal agent workflows are the ways individuals use a single AI agent, often described as a chief of staff, to triage email, summarise meetings, manage the calendar and delegate to specialised sub-agents over chat.

15 linksconcept

Vertical integration of AI labs

Vertical integration of AI labs is model developers extending from models into the layers around them: buying developer toolchains, owning coding harnesses, moving into consumer verticals and cutting off third-party platforms.

8 linkstechnique

Automated software maintenance

Automated software maintenance is the use of coding agents to do the upkeep of a codebase, such as fixing bugs, removing technical debt, upgrading dependencies and re-architecting, without a human driving each task.

10 linksmetric

Enterprise agent tokens

Enterprise agent tokens is the share of an enterprise customer base's token consumption that goes to agentic tools rather than chat, reported by OpenAI at 64 percent for Codex against ChatGPT by June 2026.
