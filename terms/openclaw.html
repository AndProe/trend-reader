OpenClaw

first seen 2026-W32 · 7 links · 1 min read

An open-source, self-hosted agent harness that lives on a machine the user provides (a laptop, Mac Mini or VPS), connects any model to messaging apps such as Telegram and WhatsApp, keeps memory in Markdown files and a skills system, and reaches tools through MCP; the project that made "an agent living on your machine" a mainstream idea and the user-owned counterpart to managed agent computers like Grok Bot.

Also seen as OpenClaw 2.0, open-source personal agent

How the sources use it

  • Yunhao Feng, Ruixiao Lin, Ming Wen et al. (arXiv cs.AI, 2026-09-14) used in this note; see Evidence.
  • Dan McAteer (Latent Space, 2026-09-05) the user-owned alternative to Grok Bot: a gateway you run yourself, more freedom and more setup; OpenClaw 2.0 narrowed the gap with a quick start reusing a Claude Code or Codex login.
  • Will Raphaelson (Technically, 2026-08-18) the open general-purpose harness, connecting any model to Telegram and WhatsApp with memory and skills.
  • Tereza Tizkova (Technically, 2026-08-06) the project that made "an agent living on your machine" mainstream; a harness, reachable through MCP.
