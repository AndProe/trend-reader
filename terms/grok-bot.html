Grok Bot

first seen 2026-W33 · 8 links · 3 min read

Grok Bot is an agent app built on Grok 4.6 that hides the machinery of an agent behind a chat interface. Each user has a single named bot that persists between sessions, runs on a hosted computer in the cloud, can be taught skills, can operate a browser, and can hold conversations with other users' bots. Reviewers who ran it for days described it as the power of self-hosted agent stacks with the simplicity of a consumer app, and several adopted it as their daily agent harness.

For an executive the product is a signal of where knowledge-work tooling is going: away from the developer-oriented IDE and toward a persistent assistant with its own computer. It raises immediate questions about data governance, since the bot acts on the user's accounts, and about vendor concentration, since Cursor and xAI now own the model, the harness and the user relationship. It is also the most-reviewed product in this vault, which reflects how much attention the format is drawing.

Also seen as Grok Bot (Cursor/xAI)

Deeper dive

What it is. Grok Bot is the joint product of Cursor and xAI, launched in August 2026 on Grok 4.6. It is a simplified, chat-native agent for general knowledge work rather than a coding tool, with hidden reasoning, plugin support and the ability for bots to talk to each other. The design choice that defines it is one persistent bot per user, with a name and a memory, rather than a fresh session each time.

How it works. The bot runs on a Managed agent computer: a hosted machine with a filesystem, a browser and installed tools that the user never administers. Browser control lets it act on web applications, and a Skill library lets the user teach it procedures that persist. Inter-agent conversation means one user's bot can negotiate or coordinate with another's, which turns Personal agent workflows into something closer to a network. Reviewers compared it directly to OpenClaw, the self-hosted harness it displaced for several of them, and the summary was that it delivers similar power without the setup.

Trade-offs. A persistent bot accumulates context and access, which makes it more useful over time and more dangerous when it errs. The product is cited as an example of a system that does not implement a reset between tasks, so the question of how long an agent should live before its state is cleared applies directly, and Agent identity becomes a real concern once bots interact with each other. Hidden reasoning improves the experience and reduces the user's ability to audit a decision. Vendor lock-in is the commercial cost: the bot's skills, memory and hosted computer live with Cursor and xAI.

What to watch. Whether rival labs ship persistent, named agents with hosted computers as a standard product form. How Grok Bot handles enterprise controls such as data residency and audit logs. And whether inter-agent conversation produces useful coordination or becomes a security surface.

Related terms

technique

Managed agent computer

A managed agent computer is a vendor-operated persistent virtual machine assigned to each user or agent, on which the agent works and which the user can watch, as opposed to an agent that runs on the user's own device.

9 linksconcept

Agent identity

Agent identity is a verifiable, durable identity for a persistent agent: a stable named entity with its own account, credentials and history rather than a disposable session.

needed by 1 · 11 linksconcept

Personal agent workflows

Personal agent workflows are the ways individuals use a single AI agent, often described as a chief of staff, to triage email, summarise meetings, manage the calendar and delegate to specialised sub-agents over chat.

15 linkstechnique

Skill library

A skill library is a store of reusable, named procedures that an agent can load and apply, whether taught by demonstration, written by hand as instructions, derived from failure diagnoses or compiled into executable artefacts.

9 linkstechnique

Browser control

Browser control is the capability of an AI agent to operate websites and desktop applications through a persistent browser or computer session, clicking, typing and reading screens rather than calling an API.

10 linksproduct

OpenClaw

OpenClaw is an open-source, self-hosted agent harness that runs on hardware the user owns, connects any model to messaging apps such as Telegram and WhatsApp, and keeps memory in plain Markdown files alongside a skills system and MCP tool access.
