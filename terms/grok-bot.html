Grok Bot

first seen 2026-W33 · 8 links · 1 min read

Cursor and xAI's chat-native agent app for general knowledge work: a persistent named bot per user with a hosted computer, taught skills, browser control and inter-agent conversations; the vault's most-reviewed product, covered by four sources.

Related terms

technique

Managed agent computer

A vendor-operated persistent virtual machine per user or agent (Grok Bot's default), contrasted with the local-first default of Codex and Cursor; convenient, and the reason bots share logins.

9 linksconcept

Agent identity

A verifiable, durable identity for a persistent agent: a stable named character rather than a disposable thread, and the first layer on which permissions, reputation and accountability can be built.

Personal agent workflows

Individuals using a single agent or chief-of-staff bot to triage email, summarise meetings, coordinate the day and delegate to sub-bots over chat; the consumer-side pattern Grok Bot and Orosz's inbox agent illustrate, and Sottiaux's rationale for a universal personal agent.

Browser control

10 linksproduct

OpenClaw

An open-source, self-hosted agent harness that lives on a machine the user provides (a laptop, Mac Mini or VPS), connects any model to messaging apps such as Telegram and WhatsApp, keeps memory in Markdown files and a skills system, and reaches tools through MCP; the project that made "an agent living on your machine" a mainstream idea and the user-owned counterpart to managed agent computers like Grok Bot.
