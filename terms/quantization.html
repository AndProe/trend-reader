Quantization

first seen 2026-W36 · 7 links · 3 min read

Quantization is compression for AI models. A trained model stores billions of numbers at high precision; quantization stores them with fewer bits, much as audio compression discards detail a listener will not notice. Common formats include INT8, 4-bit variants such as NF4 and GGUF Q4, and the newer NVFP4 supported directly by recent hardware. A 4-bit version of a model needs roughly a quarter of the memory of the original, which is the difference between needing a data-centre GPU and running on a laptop or a hobbyist's graphics card.

For an executive quantization is a cost lever and a deployment enabler. It is why open models of 27 billion parameters run on desktop machines, why on-device inference is viable, and why serving costs per token keep falling. The caveat is that precision affects accuracy, so hardware comparisons that mix precisions are not like-for-like, and a quantized model should be re-evaluated on the tasks that matter before it replaces a full-precision one.

Also seen as post-training quantization, low-precision serving, NVFP4, GGUF Q4

Deeper dive

How it works. Post-training quantization maps each high-precision weight to the nearest value in a coarser grid, typically per block of weights with a scale factor so that the grid adapts to the local range. Activations can be quantized too, which is what allows hardware to run the matrix multiplications in low precision rather than only storing weights compactly. Formats differ in how they allocate bits: INT8 is a uniform grid, NF4 uses a distribution-aware grid tuned to weight statistics, and NVFP4 is a floating-point 4-bit format with hardware support on recent accelerators. Quantization-aware training and calibration on sample data reduce the quality loss further. In generative video, step distillation plays an analogous role, reducing the number of denoising steps to reach real time.

Why it matters now. Quantization underpins On-device inference and Edge AI: hobbyists deploy 4-bit builds of 27-billion-parameter models on small desktop machines and consumer graphics cards, and 4-bit has become the default for running open weights locally. For data centres it improves Performance per watt and Energy efficiency, since fewer bytes moved per token means less power. Precision has also become a fairness line in hardware benchmarking, with results at FP8 and FP4 compared directly even though the lower precision trades some accuracy for speed. Sustainability work now treats quantization as a systems choice, weighing memory, energy and accuracy together, rather than as a monotonic trade-off where less precision is always worse.

Trade-offs. The quality cost is task-dependent and can be hidden: a quantized model may match the original on standard benchmarks and degrade on long reasoning, rare languages or numerically sensitive tasks. Aggressive quantization interacts badly with some architectures, and mixed-precision schemes add engineering complexity. There is also a strategic tension with Small language models: a heavily quantized large model and a full-precision small model can occupy the same memory budget with different strengths, and which wins depends on the workload.

What to watch. Adoption of 4-bit floating-point formats in hardware and serving stacks, whether benchmark reporting standardises on stated precision, and how far quality-preserving quantization can push frontier-class models onto consumer devices.
