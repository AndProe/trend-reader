Dreaming

An agent working on a task cannot know which of its observations will matter later, and asking it to decide in-flight spends context on bookkeeping. Dreaming moves that judgment after the fact: a second agent reads the completed session and writes what is worth remembering into a store the next session will read.

The appeal is that it is built from parts that already exist. Where a managed-agent platform separates the persistent session and harness from the ephemeral execution sandbox, the session record is already durable and inspectable — so memory consolidation becomes a matter of running another agent over it rather than adding a new subsystem. That makes dreaming a composition rather than a capability, which is why it has appeared as a worked feature on one platform and as an architectural variable in world-model research within the same period.

Also seen as agent dreaming, offline memory consolidation

Deeper dive

How it works. The minimal implementation is exactly as the name suggests: one agent reads another's prior trajectory and writes memories back. What distinguishes implementations is what gets written and how it is retrieved — free-text notes, structured lessons, or weight-level artefacts as in adapter-library approaches. Retrieval is the harder half: a memory store that is not routed from accurately is indistinguishable from no memory, which is why adjacent designs pair consolidation with explicit promotion and retirement of notes, so a memory contradicted by a changed system is quarantined rather than reused.

Why it matters now. Two things converged. Agent sessions became long enough that Context rot is the normal failure rather than an edge case, so what survives a session boundary determines whether an agent improves. And platforms began exposing the session log and harness as persistent objects separate from execution, which made the record available to a second agent at all. The term also now spans two domains: in world models, dreaming describes a model exploring its own generated environment, where the same retrieval question appears as whether a region is regenerated consistently.

Trade-offs. Consolidation by a second agent inherits that agent's judgment, so a wrong lesson persists with the same durability as a right one, and nothing in the loop verifies it. Stored memories also go stale as the underlying system changes, which turns an asset into a liability unless contradiction is detected. Measured results elsewhere are mixed rather than uniformly positive — explicit shared memory has helped some model families and hurt others on the same tasks — which suggests the benefit depends on how a model was trained to use supplied context. And the technique adds cost: another agent run per session, spent on work with no immediate output.

What to watch. Whether written memories are validated or merely accumulated, whether retirement mechanisms become standard, and whether consolidation moves from text stores into parameters as adapter-based approaches mature.

Working memory

Sub-agents are parallel agents spawned inside a single run under a coordinator, each given a slice of the task and its own context, with results returned to the parent.

Continual learning

Continual learning is the ability of a model to keep learning from its deployment, updating on new tasks, users and information while retaining what it already knows, instead of being frozen at the end of training.

Skill library

A skill library is a store of reusable, named procedures that an agent can load and apply, whether taught by demonstration, written by hand as instructions, derived from failure diagnoses or compiled into executable artefacts.

Persistent agents

Persistent agents are AI agents designed to run continuously and carry memory, identity and relationships across sessions, devices and tasks, instead of starting fresh on each request.

Self-verification is an AI system checking its own work before declaring it done, either inside the model's reasoning or through a harness that runs tests, reads telemetry, inspects screenshots and selects among candidate answers.
