Coding harness

first seen 2026-W25 · needed by 9 · 28 links · 2 min read

The tooling layer around a model that turns it into a coding agent (Claude Code, Codex, Cursor, Devin, Ramp's Inspect on OpenCode), now the product unit of the agentic era and extended beyond code. Orosz's term; the harness plus model is what SemiAnalysis dates the era from.

Also seen as AI harness, harnesses, AI coding harness, aftermarket harnesses, open source harness

How the sources use it

  • David Krevitt (Technically, 2026-09-22) the agent deploys in minutes, sets up CI well, and is the reason the change volume needs automated checks; Krevitt draws the line at reading error logs. Recurring and cross-source (Gergely Orosz, Matthew Berman, SemiAnalysis, Tomasz Tunguz).
  • Trang Nguyen, Eulrang Cho, Bingqing Chen, Tim Dettmers (arXiv cs.AI, 2026-09-22) Cross-source (Gergely Orosz, Matthew Berman, SemiAnalysis, Technically); the method is delivered as an API proxy sitting under existing harnesses rather than inside one.
  • Latent Space (Latent Space, 2026-09-21) Claude Code and Codex as single-model designs against open harnesses that can adopt a second model class. Cross-source (Gergely Orosz, SemiAnalysis, Technically, Tomasz Tunguz).
  • Run-Ze Fan, Zihao Zhang, Simin Ma et al. (arXiv cs.AI, 2026-09-17) cross-source (Gergely Orosz, SemiAnalysis, Technically); the paper decomposes the harness into components and measures each.
  • Tomasz Tunguz (Tomasz Tunguz, 2026-09-17) the measured swap is between two coding harnesses on coding benchmarks. Recurring (W32); cross-source.
  • Gergely Orosz (Gergely Orosz, 2026-09-09) the harness as crutches that shrink as models improve.
  • Leitian Tao, Baolin Peng, Haorui Wang et al. (arXiv cs.AI, 2026-09-08) cross-source; the test-verify-revise scaffold with a fail-closed test harness.
  • Gergely Orosz (Gergely Orosz, 2026-08-25) (aliases: AI harness, harnesses) — the tooling layer around a model; Inspect uses OpenCode as its harness.
  • Dylan Patel (SemiAnalysis, 2026-08-21) Orosz's term; the model-plus-harness product as the era's defining unit.
  • Gergely Orosz (Gergely Orosz, 2026-08-14) the agent harness pattern, now extended beyond code.
  • Justin Gage (Technically, 2026-08-11) Claude Code, v0, Replit and Bolt as the harnesses that make stack decisions on the user's behalf.
  • Tomasz Tunguz (Tomasz Tunguz, 2026-08-09) the category label Tunguz applies to Harvey, Legora, Sierra, Ramp and Decagon; the same term Orosz and Berman use this month for coding-agent tooling, applied here to vertical AI products.
  • Matthew Berman; Nader Dabit (Matthew Berman, 2026-08-07) the broader category (Devin, Cursor, Codex, Claude Code) whose future improvement potential is discussed.
  • Paul Iusztin (Technically, 2026-07-21) Claude Code, Cursor and Codex as harnesses, and the limits of customising them for other jobs.
