Claude Code

first seen 2026-W17 · 9 links · 3 min read

Claude Code is a program that runs in a developer's terminal and hands a Claude model the ability to read and edit files, execute commands, run tests and call other tools. The developer describes a task; the agent works through it in a loop and returns with changes ready for review. Unlike an autocomplete plug-in, it operates on the whole repository and takes stack and architecture decisions on the user's behalf, and is often described as building the whole application rather than assisting with parts of it.

For executives it matters in three ways. It defines the shape of the agentic inference workload now driving data-centre demand, since its traces underpin the main agentic serving benchmark. It is a closed harness tied to one lab's models, so adopting it is a vendor commitment, and companies such as Ramp have built their own agents on open harnesses to keep that option. And it sets the productivity baseline against which internal engineering plans are now judged.

Also seen as Claude Code (Anthropic)

Deeper dive

How it works. Claude Code is a Coding harness: a control loop around a model that manages context, tool calls and verification. The model reads the repository, proposes edits, runs commands and tests, and iterates on failures. It uses keyword and file-system search rather than a vector index to find relevant code, delegates independent work to Sub-agents, and can drive a package manager, CI setup and deployment on every invocation. The design is single-model: the harness is built for Claude and does not swap in another lab's model, which distinguishes it from open harnesses that can adopt a second model class.

Why it matters now. Two things make Claude Code central rather than one product among several. First, its release in November 2025 is treated as the inflection point from which the agentic era is dated, because it was the first widely used tool where the model-plus-harness unit did end-to-end engineering work. Second, its execution traces are the workload behind the AgentX benchmark that measures Agentic inference workloads on different hardware, so its behaviour shapes how the industry thinks about serving cost. Each lab's model now favours its own coding agent, which turns the harness into an application moat and a case of Vertical integration of AI labs, with the lab owning model, runtime and agent.

Trade-offs. Autonomy is the benefit and the cost. The agent will make stack decisions without explaining them, which suits fast delivery and vibe-coded prototypes but leaves teams without understanding of what was built. Its closed design means no model portability, so enterprises that want to route work across labs or govern cost per task put a proxy under it or choose an open harness instead; Ramp's Inspect, built on OpenCode, is the cited example. Research on compaction and harness component design shows that much of the cost of long-horizon runs sits in the harness rather than the model, so the harness vendor's engineering choices become the customer's bill.

What to watch. Whether Specialised harnesses for non-coding work grow out of it, how its scores on SWE-bench Verified and terminal benchmarks compare with Codex as the two labs race, and whether Anthropic opens the harness to other models or keeps it as a moat.

Sub-agents

Sub-agents are parallel agents spawned inside a single run under a coordinator, each given a slice of the task and its own context, with results returned to the parent.

Agentic inference workloads

Agentic inference workloads are the production traffic pattern created by coding and computer-use agents: many turns per task, context that accumulates toward a million tokens, very high reuse of shared prefixes, and bursts of parallel sub-agent calls.

needed by 1 · 16 linksconcept

Vibe coding

Vibe coding is building software by prompting a coding agent and accepting what it produces without understanding the stack, vendors or architecture it chose.

13 linksconcept

Vertical integration of AI labs

Vertical integration of AI labs is model developers extending from models into the layers around them: buying developer toolchains, owning coding harnesses, moving into consumer verticals and cutting off third-party platforms.

8 linksconcept

Specialised harnesses

Specialised harnesses are agent products that wrap a general model in one domain's tools, prompts, data connections and guardrails, such as Harvey for legal research, Abridge for clinical notes, Sierra for customer service and Glean for enterprise search.
