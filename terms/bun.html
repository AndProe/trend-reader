Software performance

Making code fast, treated by Casey Muratori as under-valued and only recoverable when the architecture allowed for it; hotspot profiling versus design, and Python's amplification cost pushing labs to other languages.

6 linksconcept

AI-assisted migrations

Using coding agents to execute large framework, language or test-suite migrations that were previously impractical, with retry-and-verify pipelines doing most of the work.

11 linksconcept

Vertical integration of AI labs

Frontier labs extending from models into the layers around them, buying developer toolchains (Anthropic and Bun, OpenAI and Astral), owning coding harnesses and cutting off third-party platforms, so that the product, not the model, is where they compete; the counter-position to model-agnostic architecture.

8 linksconcept

Package registry

The public warehouse of open-source packages (PyPI, the npm registry, RubyGems) from which package managers fetch dependencies, which Will Raphaelson (Technically) describes as a layer coding agents now hit many times a minute rather than a human occasionally.
