Long context

first seen 2026-W34 · needed by 4 · 12 links · 3 min read

Long context means the model can take in a very large amount of material in a single request, on the order of a million tokens, roughly the length of several long novels. In practice this is what allows a coding agent to hold a whole repository and hours of tool output in mind, a clinician to load a patient's longitudinal record, or a video model to reason over multi-hour footage without cutting it into frames.

For executives the term matters in three ways. It sets the ceiling on how long an agent can work before its context must be compacted, which bounds the tasks agents can be given. It is the dominant cost driver in serving, because memory for context rather than compute for tokens is what fills a machine. And it is unevenly reliable: models degrade as the window fills, so a system that nominally accepts a million tokens may not use them well. Procurement and architecture decisions should distinguish between advertised window size and usable window size.

Also seen as 1M context, long context window

Deeper dive

How it works. A transformer's context window is the number of tokens it can attend over in one pass. Extending it from thousands to a million tokens required architectural changes to positional encoding, attention efficiency and training data, but the binding constraint in production is memory: the KV cache grows with every token, so a 500,000-token agent prefill occupies gigabytes of accelerator memory per session, and on SRAM-based machines with tens of gigabytes per wafer the window is a hard ceiling. In agent serving, reading the cache dominates the decode step, which pushes hardware design toward memory bandwidth and capacity. Compaction, in which the agent summarises earlier context to free space, has its own cost curve, with a million tokens the practical ceiling before compaction becomes mandatory.

Why it matters now. Agentic inference workloads consist of long sessions that append tool output, code and reasoning to one context, so window size is what allows Long-horizon goals to run for hours. New application classes depend on it: longitudinal medical records across many encounters, stacks of documents with no explicit question, genomics that needed long windows years before natural-language products did, and multi-hour video where an agentic loop replaces stuffing frames into context. Research on harness design treats the bounded window as the constraint on multi-session work, and among the improvements discovered by self-improving research agents are memory mechanisms for their own growing context.

Trade-offs. Context rot is the reliability cost: retrieval and reasoning quality fall as the window fills, and noisy histories become too long to reason over directly, which motivates latent memory graphs and other compression. Sparse attention reduces compute but not the need to store the full cache. Re-prefilling a long context after an edit scales with everything the cache holds, so document-editing agents need cache repair rather than recomputation. The context dial is therefore a cost lever that engineers should set deliberately rather than leave at maximum.

What to watch. Usable-context benchmarks that measure quality at the far end of the window, the price gap between short and long requests, and whether memory mechanisms outside the window make the window itself less important.

Related terms

technique

KV cache

The KV cache is the per-token store of key and value vectors that a transformer keeps during generation so it does not recompute attention over the whole context on every step.

needed by 2 · 12 linksconcept

Context rot

Context rot is the degradation of an AI agent's performance and memory reliability as its conversation history accumulates, even when the total stays within the model's nominal context window.

9 linkstechnique

Sparse attention

Sparse attention is a family of attention mechanisms in which each token attends to a selected subset of positions rather than to every previous token, so that the cost of long contexts grows less than quadratically.

6 linksconcept

Agentic inference workloads

Agentic inference workloads are the production traffic pattern created by coding and computer-use agents: many turns per task, context that accumulates toward a million tokens, very high reuse of shared prefixes, and bursts of parallel sub-agent calls.

needed by 1 · 16 linksconcept

Long-horizon goals

Long-horizon goals are objectives that an agent pursues autonomously over days, maintaining coherence across billions of tokens and many sub-tasks rather than completing one request and stopping.

needed by 1 · 12 linksconcept

Vision-language models

Vision-language models are models that take images and text together and reason over both, serving as the perception layer for computer-use agents that read screens and as the basis of visually grounded reasoning research.
