Skill library

first seen 2026-W23 · 9 links · 3 min read

When an agent completes a task, the knowledge of how it did so usually evaporates with the session. A skill library keeps it. A skill can be a short document of instructions the agent reads when a matching task arrives, a recording of a demonstrated workflow such as logging a price into a spreadsheet, or a versioned procedure generated from an analysis of what went wrong last time. Products now let users teach skills by showing the agent once.

For an executive skills are the packaging layer for expertise. A team's way of doing code review, domain modelling or page layout can be written as a skill and given to every agent in the company, which is how non-engineering teams have started shipping software. Vendors supply skills for their own products in the way they once supplied templates. The risk is that hand-written skills become training wheels that limit a more capable model, so a skill library needs curation and retirement, not just accumulation.

Also seen as taught skills, reusable skills, agent skills

Deeper dive

How it works. A skill is a named unit with a trigger and a body. The simplest form is a markdown file describing when to apply it and what steps to follow, loaded into the agent's context when a task matches; this is how workflows such as grill-me, wayfinder, test-driven development and domain modelling are distributed among practitioners. A taught skill records a demonstrated sequence of actions in a browser or application and replays it with parameters. A learned skill is derived from failure traces: the system diagnoses why a run failed, writes a corrective procedure, versions it and applies it next time, and a second agent may edit the skill bank between runs. The most structured form compiles skills into finite state machines rather than prompt text, so execution is deterministic. Skills sit alongside MCP tool connections as the two ways an agent's capabilities are extended without retraining, and they are a building block of Personal agent workflows.

Why it matters now. Skill libraries are how AI agents retain competence across sessions and across users. Research frameworks orchestrate skills at runtime, register workflows as discoverable components, and build and refine skills cheaply with bandit-guided selection. In products, taught skills in consumer agents and vendor-supplied skills for coding agents show the same idea at both ends of the market, and one team replaced content-management templates with one skill per page type because the agent follows the rules a template only suggests. Self-organisation in agent systems has been defined as a failure class becoming a new skill.

Trade-offs. A skill encodes today's best practice and yesterday's model limitations. Hand-written skills that scaffolded a weaker model can constrain a stronger one, so the library needs review as models improve. Skills derived from failures can overfit to the failure. Compiled skills are reliable but rigid. Libraries also raise a governance question, since a skill that acts through Browser control or tools carries permissions, and a shared library distributes them. Specialised harnesses are in effect skill libraries frozen into a product for one domain.

What to watch. Whether skill formats converge on a standard the way tool protocols did, how libraries are curated at company scale, and whether models begin to author and prune their own skills without human review.

AI agents

Browser control

Browser control is the capability of an AI agent to operate websites and desktop applications through a persistent browser or computer session, clicking, typing and reading screens rather than calling an API.

MCP

MCP, the Model Context Protocol, is an open standard for exposing tools, data sources and device controls to AI agents through a uniform server interface.

8 linksconcept

Personal agent workflows

Personal agent workflows are the ways individuals use a single AI agent, often described as a chief of staff, to triage email, summarise meetings, manage the calendar and delegate to specialised sub-agents over chat.

15 linksconcept

AI research tools

AI systems used to do research: gathering and reading sources, running literature searches, operating instruments and, at the far end, acting as scientist workspaces that plan and execute experiments.

6 linksproduct

OpenClaw

OpenClaw is an open-source, self-hosted agent harness that runs on hardware the user owns, connects any model to messaging apps such as Telegram and WhatsApp, and keeps memory in plain Markdown files alongside a skills system and MCP tool access.
