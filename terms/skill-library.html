Skill library

first seen 2026-W23 · 9 links · 1 min read

Reusable, named automations an agent learns from a demonstration or stores as first-class objects (Grok Bot's taught skills, Dr. Claw's skills), so that a task done once becomes a capability.

Also seen as taught skills, reusable skills, agent skills

How the sources use it

  • Yanzhang Ma, Zhenghan Tai, Hanwei Wu et al. (arXiv cs.AI, 2026-09-17) cross-source (Matthew Berman, Technically); here skills are derived from failure diagnoses and versioned, not taught by demonstration.
  • Yuqi Ping, Tianhao Liang, Nanchi Su et al. (arXiv cs.AI, 2026-09-17) cross-source (Matthew Berman, Latent Space, Technically); the case study reuses a verified image-delivery skill.
  • Gergely Orosz (Gergely Orosz, 2026-09-17) markdown skills (grill-me, wayfinder, TDD, domain modelling) as the distribution mechanism for a workflow. New for this source; cross-source (arXiv, Latent Space, Matthew Berman, Stratechery, Technically).
  • Nilesh Verma, Nick Lim, Albert Bifet et al. (arXiv cs.AI, 2026-09-16) cross-source (Matthew Berman, Technically); registered workflows become discoverable components, which is a skill store inside a library.
  • Richard MacManus (Latent Space, 2026-09-15) COS-PLAY's learnable skill bank edited by a second agent between runs.
  • Pingchen Lu, Xiangyi Wang, Xiang Li et al. (arXiv cs.AI, 2026-09-10) cross-source (Berman, Stratechery, Technically); the paper is a method for building and refining reusable agent skills cheaply.
  • David Krevitt (Technically, 2026-09-08) Clerk's agent Skills as vendor-supplied patterns for coding agents.
  • Ben Thompson (Stratechery, 2026-09-04) hand-written skills as training wheels that become a limiter for a more capable model. Cross-source (Berman, Latent Space).
  • Dingjie Song (arXiv cs.AI, 2026-08-31) reusable skills as a first-class object, the same mechanism Berman demonstrates in Grok Bot's taught skills.
  • Matthew Berman (Matthew Berman, 2026-08-12) converting a manually demonstrated task (Berman logging a camera price to a spreadsheet) into a reusable, named automation skill.
  • Matt Henderson (Technically, 2026-06-04) one Skill per page type as the replacement for CMS templates, "the agent actually follows the rules".

Related terms

concept

AI agents

Software systems in which a language model plans, calls tools and acts over many steps toward a goal, rather than answering a single prompt.

needed by 20 · 33 linkstechnique

Browser control

Agents operating websites and desktops through a persistent browser or computer session: purchases, returns, form-filling, professional workflows.

10 linkstechnique

MCP

Model Context Protocol, the standard for exposing tools to agents; hosted internally at Optiver so agents use company tools, and one of the protocols NLIP positions itself against.

8 linksconcept

Personal agent workflows

Individuals using a single agent or chief-of-staff bot to triage email, summarise meetings, coordinate the day and delegate to sub-bots over chat; the consumer-side pattern Grok Bot and Orosz's inbox agent illustrate, and Sottiaux's rationale for a universal personal agent.

15 linksconcept

AI research tools

AI systems used to do research: gathering sources, running literature searches and, in the arXiv line, acting as scientist workspaces.

6 linksproduct

OpenClaw

An open-source, self-hosted agent harness that lives on a machine the user provides (a laptop, Mac Mini or VPS), connects any model to messaging apps such as Telegram and WhatsApp, keeps memory in Markdown files and a skills system, and reaches tools through MCP; the project that made "an agent living on your machine" a mainstream idea and the user-owned counterpart to managed agent computers like Grok Bot.
