Agent protocols

first seen 2026-W35 · needed by 2 · 6 links · 1 min read

The emerging interoperability layer for agents (MCP, A2A, NLIP): how agents call tools and talk to each other across vendors, with security designed in or not.

Also seen as NLIP, A2A, agent interaction protocol

How the sources use it

  • Laxmipriya Ganesh Iyer (arXiv cs.AI, 2026-09-16) cross-source (Frontier Labs); the finding is protocol-level, arising from how servers are merged.
  • Luyi Xing (arXiv cs.AI, 2026-09-03) the emerging layer including MCP and A2A.
  • Anthropic (Frontier Labs, 2026-08-27) MHS is a protocol layer for agents operating devices, positioned next to MCP the way NLIP and A2A are in the arXiv line. Cross-source (arXiv).

Related terms

technique

MCP

Model Context Protocol, the standard for exposing tools to agents; hosted internally at Optiver so agents use company tools, and one of the protocols NLIP positions itself against.

8 linksconcept

Agent interoperability

Agents from different vendors working together across a shared platform or protocol; Meta's stated reason for standardising on Slack and the goal of protocol proposals such as NLIP and A2A.

5 linksconcept

Agent identity

A verifiable, durable identity for a persistent agent: a stable named character rather than a disposable thread, and the first layer on which permissions, reputation and accountability can be built.

needed by 1 · 11 linkstechnique

Agent-to-agent messaging

Specialised agents talking to each other directly as a product feature, with those conversations persisting as their own threads; distinct from the emergent coordination agents invented for themselves.
