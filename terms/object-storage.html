Object storage

first seen 2026-W29 · 4 links · 1 min read

Cloud storage for files and unstructured data as a bottomless, cheap, separately billed service (AWS S3 since 2006); the layer on which Snowflake, Databricks, Neon and Turbopuffer rebuilt data infrastructure by separating storage from compute, and where a vibe-coded app keeps its images and PDFs while the database keeps only the link.

Also seen as S3, blob storage, buckets

How the sources use it

  • David Krevitt (Technically, 2026-08-25) where big files go: a giant labelled locker (S3, a Railway Bucket) that the database keeps only a link to.
  • David Krevitt (Technically, 2026-07-14) the foundation layer (S3) that a generation of data companies and now AI search are rebuilt on.
