Memory poisoning

first seen 2026-W35 · 6 links · 1 min read

A malicious email, document or calendar invite hijacking a long-lived agent through its persistent context; the risk Tunguz sets against long agent lifetimes.

Also seen as context poisoning, prompt injection via memory

How the sources use it

  • Ivan Aleksandrov, German Kochnev, Sabrina Sadiekh, Yaroslav Rogoza (arXiv cs.AI, 2026-09-21) Cross-source (Tomasz Tunguz); RAG poisoning is one of the named vulnerability classes.
  • Fayeq Jeelani Syed, Rehan Ahmad, Ali Al Bataineh, Aakriti Adhikari (arXiv cs.AI, 2026-09-19) Cross-source (Tomasz Tunguz); memory contamination and cross-session data leakage are two of the five named failure modes.
  • Tomasz Tunguz (Tomasz Tunguz, 2026-08-24) a malicious email or calendar invite hijacking a long-lived agent's persistent context.

Persistent agents

Agents intended to run continuously, keeping memory, reputation and relationships across tasks, rather than on a scheduled or rationed basis; the aspiration behind always-on assistants and the case for local inference.

Context rot

The degradation of an agent's performance and memory reliability as its conversation history accumulates; Tunguz's reason to ask how long an agent should live.
