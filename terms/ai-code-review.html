AI code review

first seen 2026-W23 · 8 links · 1 min read

Models reviewing code changes, multi-model in Greptile's case, and the diff-review habit borrowed back into prose editing; the tooling answer to the review burden AI-generated code creates.

Also seen as automated code review, diff review

Code review

The human review of changes before merge, now an overloaded ritual under AI-generated volume: product decisions stay human, validation moves to tooling, and some teams treat it as optional.

Verification loops

Pipelines that retry and validate each change until it passes tests, the common ingredient in every AI-migration success story and the basis of software factories.

Software factory

Agents running the reproduce, fix, review and verify loop end to end with humans setting rules and reviewing a fraction; the end state of loop engineering, in production at Vercel for 25 to 35 percent of merged PRs and contested as a metaphor by Orosz.

LLM-as-judge

Database schema
