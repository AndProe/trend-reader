Remote sandboxes

first seen 2026-W25 · 6 links · 1 min read

Cloud machines spun up per agent session for unlimited concurrency and central configuration; how Ramp runs Inspect and the infrastructure behind hosted agent computers.

Also seen as remote dev environments, cloud development environments, per-session sandboxes

Coding harness

The tooling layer around a model that turns it into a coding agent (Claude Code, Codex, Cursor, Devin, Ramp's Inspect on OpenCode), now the product unit of the agentic era and extended beyond code.

Managed agent computer

A vendor-operated persistent virtual machine per user or agent (Grok Bot's default), contrasted with the local-first default of Codex and Cursor; convenient, and the reason bots share logins.

Sandbox escape

An agent getting past its isolation: GET-based writes through an allow-listed proxy and the /etc/hosts bypass Willison documented, or the 13-year-old Chrome bug found by automation.

needed by 1 · 8 linkstechnique

Sub-agents

Parallel agents spawned inside a run under a coordinator, now too many to read and the source of bursty serving traffic; dozens with bounded concurrency in Latent Space's Astra practice.

needed by 1 · 13 linksconcept

Package registry

The public warehouse of open-source packages (PyPI, the npm registry, RubyGems) from which package managers fetch dependencies, which Will Raphaelson (Technically) describes as a layer coding agents now hit many times a minute rather than a human occasionally.

Codex-ChatGPT merger

OpenAI's consolidation of its Codex coding agent and ChatGPT into one interface and harness, which Tibo Sottiaux told Berman is a bet on a single personal-AGI interface that adapts to technical and non-technical users alike rather than a product consolidation.
