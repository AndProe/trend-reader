Browser control

first seen 2026-W34 · 10 links · 3 min read

Browser control, also called computer use, means an agent drives software the way a person does: it looks at the screen or the page structure, decides what to click or type, and checks the result. Instead of waiting for a vendor to provide a connector, the agent can use any website or application that has a user interface. It was the strongest professional skill in early reviews of GPT-6 Astra and is now described as essentially solved.

For executives this changes the integration calculation. Workflows that were blocked because a supplier had no API can now be automated, and a court's dismissal of Amazon's suit against Perplexity's shopping agents removed a legal obstacle for agents acting on consumer sites. The risks sit in access and accountability: an agent with a logged-in browser holds the user's credentials and can complete irreversible actions, so scoping what it may reach becomes a governance decision.

Also seen as computer use, browser use, browser agents, browser-based agentic workflows, Browser-based agentic shopping, computer use agents

Deeper dive

How it works. A browser-control agent runs in a loop: capture the current state, decide an action, execute it, observe the result. State can be a screenshot interpreted by a vision model, or the page's DOM and accessibility tree, which is cheaper and more precise when it is available. Actions are clicks, keystrokes, scrolls and navigation, issued through automation tooling of the kind Playwright provides. The session is persistent, so logins, cookies and multi-step state survive between actions, and cloud-hosted variants run the browser on a server so the agent can work while the user is away. One research direction trains agents on an interface world model, a learned simulation of how interfaces respond, rather than on live sites.

Why it matters now. The capability crossed from demonstration to product with GPT-6 Astra, where computer use was the largest single leap over the previous generation and was reported as about twice as fast as GPT-5.6. Reviewers described it as the end of the connector era: rather than each service exposing an API, the agent uses the interface people already have. Consumer cases include purchases, returns and food orders through hosted browser agents, which became legally clearer after a court dismissed Amazon's suit against Perplexity's shopping agents. Professional cases include self-recorded browser tasks that the agent replays and adapts, and frontend checks that continuous integration cannot make. Products such as Grok Bot and the Managed agent computer pattern package the same loop for personal and enterprise use.

Trade-offs. Screen-based operation is general but slow and token-hungry compared with an API call, and it breaks when interfaces change. Sites may block automated sessions or serve different content to them. A logged-in browser is a credential store, so prompt injection through page content is a live risk; the agent reads the page and the page may instruct it. Reliability is measured on suites such as OSWorld, where progress is fast but far from perfect on long tasks.

What to watch. Whether reusable procedures accumulate in a Skill library so agents stop re-deriving the same workflows; whether sites move to agent-specific interfaces; and how Vision-language models versus DOM-based approaches divide the market.

Managed agent computer

A managed agent computer is a vendor-operated persistent virtual machine assigned to each user or agent, on which the agent works and which the user can watch, as opposed to an agent that runs on the user's own device.

Grok Bot

Grok Bot is the chat-native agent application from Cursor and xAI for general knowledge work: each user gets a persistent, named bot with its own hosted computer, taught skills, browser control and the ability to converse with other agents.

8 linksmodel

GPT-6 Astra

GPT-6 Astra is OpenAI's frontier model, released on 3 September 2026 and aimed at computer use, coding and security, with multi-day autonomous goal runs and prices that match Anthropic's Fable tier.

needed by 1 · 13 linkstechnique

Skill library

A skill library is a store of reusable, named procedures that an agent can load and apply, whether taught by demonstration, written by hand as instructions, derived from failure diagnoses or compiled into executable artefacts.

9 linksproduct

OSWorld

OSWorld is a benchmark of cross-application computer-use tasks run in controllable operating-system environments, on which agent scores rose from around 12 percent at its 2024 launch to the low-to-mid 80s by mid-2026, past an estimated human baseline of about 72 percent.
