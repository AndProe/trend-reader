Products & applications

How model capability reaches people: the products, interfaces and platforms built on top of it.

  1. concept

    Personal agent workflows

    A personal agent workflow puts one agent at the centre of a person's day. The user talks to it over a messaging app, it has access to email, calendar, documents and meeting transcripts, and it does the triage: which messages matter, what to reply, what the day looks like, what actions came out of the last meeting. When a task needs specialist skill it hands off to sub-agents and consolidates what it learned, often on a nightly cycle. Products such as Grok Bot package this pattern; self-hosted harnesses offer the same for people willing to run their own.

  2. concept

    Voice agents

    A voice agent listens, understands and acts. Unlike a voice assistant that reads answers aloud, it calls tools, reaches into work applications and in some cases controls physical systems such as vehicles. Google DeepMind positions Gemini 3.8 Live for complex tool-using work by speech, measures it on voice-specific agent benchmarks, extends it with a visual avatar, and ships text-to-speech models positioned for volume production; OpenAI has added an agentic mobile voice that reaches into its Work surface, and dedicated hardware is being designed to carry such products.

    Read the term →
  3. product

    Grok Bot

    Grok Bot is an agent app built on Grok 4.6 that hides the machinery of an agent behind a chat interface. Each user has a single named bot that persists between sessions, runs on a hosted computer in the cloud, can be taught skills, can operate a browser, and can hold conversations with other users' bots. Reviewers who ran it for days described it as the power of self-hosted agent stacks with the simplicity of a consumer app, and several adopted it as their daily agent harness.

  4. event

    Codex-ChatGPT merger

    OpenAI has been folding Codex, its coding agent, into ChatGPT, so that the same underlying agent machinery serves a software engineer fixing a bug and an analyst preparing a report. The visible form is ChatGPT Work, in which the full Codex harness runs on a managed cloud computer inside the ChatGPT interface. The local command-line agent is being merged into a hosted stack that OpenAI operates.

    Read the term →
  5. concept

    Ambient AI

    Ambient AI takes two forms that share one idea. In consumer hardware it means glasses, earbuds and household assistants that listen for commands, understand what is happening around the wearer, and offer help across surfaces without being opened; the argument is that conversation is multimodal and an assistant should meet it that way. In industrial settings it means small models inside appliances, vehicles and equipment that monitor continuously, where checking again costs nothing per token because the model runs locally. In both cases the goal is that users stop thinking about the AI.

    Read the term →
  6. product

    OpenClaw

    OpenClaw is a piece of open-source software that turns a laptop, a small desktop box or a rented server into a personal AI agent. The user picks the model, connects the agent to chat apps they already use, and the agent keeps its memory in ordinary Markdown files that the owner can read and edit. Skills extend what it can do, and tools are reached through the MCP standard, so it works with the same integrations as commercial agents. Version 2.0 added a quick start that reuses an existing Claude Code or Codex login, which removed much of the setup friction.

  7. product

    ChatGPT Work

    ChatGPT Work takes the machinery OpenAI built for its coding agent, Codex, and points it at non-engineering jobs. Instead of a chat window that answers questions, the user gets an agent with its own cloud computer that can open files, run tools, browse, draft and iterate over a task for as long as it takes. The underlying harness is the same one engineers use; what changes is the framing and the set of tools exposed.

    Read the term →
  8. concept

    Specialised harnesses

    A harness is everything around a model that turns it into a working agent: the tools it can call, the instructions it follows, the checks on its output and the interfaces it lives in. A specialised harness fixes all of that for one domain and sells it as a product. The lawyer using Harvey, the clinician using Abridge and the support team using Sierra are all using roughly the same underlying models; the product is the harness.

    Read the term →
  9. concept

    AI research tools

    AI research tools range from a model that gathers and summarises sources to an agent fleet that reads sequencing data and proposes experiments. Practitioners' verdict is consistent: useful for source gathering, unreliable for reasoning. The value sits in coverage, since a model can read every paper in a field, and in speed, since agents run instruments around the clock. Judgement about what matters remains human; one argument holds that the most accelerating AI in science is not a model trained on scientific data but one that helps a scientist decide what is worth doing.

  10. concept

    Agentic journalism

    Agents watch feeds such as social posts, regulatory filings, code releases and research papers, flag what is newsworthy against rules the editor has written, gather context, and produce drafts and edits. The human publishes routine items directly and reserves review for stories where judgement, sourcing or legal exposure warrants it. The result is a one-person operation at former-masthead scale. A related shift is analytics dashboards moving from reporting on content to making automated decisions about it.

    Read the term →
  11. concept

    Prompt-to-game

    Prompt-to-game means typing a short description and receiving a working game: a Portal-style puzzle, a roguelike, a 3D world or a graphical remake of a text adventure, produced in a single pass. Reviews of GPT-6 Astra made this the central evidence of the model's capability, and separate work on real-time world generation lets players control a generated environment without any scripting at all. The model fills in everything the prompt leaves out, including visual and combat design that the original never specified.

    Read the term →
  12. product

    Enterprise Frontier Safeguards

    Enterprise Frontier Safeguards is the data arrangement Anthropic introduced alongside its Fable 5.1 model. Instead of retaining customer prompts and outputs on its own systems for misuse detection, the lab stores that data in cloud infrastructure the customer controls. The customer holds the data; Anthropic keeps the right to inspect it for safety purposes.

    Read the term →
  13. concept

    AI design homogeneity

    AI design homogeneity is the design-side version of a pattern already familiar from AI writing: ask many models, or one model many times, for a product interface and the results cluster around the same palette, the same flat layout and the same component choices. Early hands-on accounts of GPT-6 Astra noted a persistent default look across projects, forest green and flat design, that a user has to work against rather than merely accept.

    Read the term →
  14. concept

    AI in medicine

    AI in medicine now spans the operating theatre, the diagnostic lab and the research bench. 2026 brought a reported world-first real-time AI-guided brain tumour removal, models that detect heart failure and valve disease from an ordinary ECG, work on modelling cancer that is limited mainly by data, and drug-repurposing efforts that find conclusions sitting unnoticed across combinations of papers no single person has read.
